# Global options

These options are accepted by every `streamx` command, at any position in the invocation.

| Option | Value | Description |
| --- | --- | --- |
| `-C`, `--context` | `<context>` | Context to use for this invocation [default: default, env: STREAMX_CONTEXT] |
| `-h`, `--help` |  | Show this help message and exit |
| `-H`, `--streamx-home` | `<streamxHome>` | StreamX home path [default: ~/.streamx, env: STREAMX_HOME] |
| `-V`, `--version` |  | Print version information and exit |
