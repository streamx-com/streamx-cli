# `streamx context configure`

Interactively configure the active context

```bash
streamx context configure [options]
```

Asks for the endpoints the CLI talks to and offers to log in. Press Enter to keep the value shown in brackets. Values are written to the context's application.properties (same as `settings set`).

## Options

| Option | Value | Description |
| --- | --- | --- |
| `-v`, `--verbose` |  | Print debug information |

---

Every command also accepts the [global options](../global-options.md).
