# `streamx context`

Manage StreamX contexts (bundled settings, event templates and login per environment)

```bash
streamx context <command>
```

## Subcommands

| Command | Description |
| --- | --- |
| [`configure`](./configure) | Interactively configure the active context |
| [`create`](./create) | Create a context and switch to it |
| [`current`](./current) | Print the active context name |
| [`delete`](./delete) | Delete a context |
| [`list`](./list) | List contexts |
| [`org`](./org/) | Manage the current organization of the active context |
| [`project`](./project/) | Manage the current project of the active context |
| [`use`](./use) | Switch the current context |

---

Every command also accepts the [global options](../global-options.md).
