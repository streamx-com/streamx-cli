# `streamx context org`

Manage the current organization of the active context

```bash
streamx context org <command>
```

## Subcommands

| Command | Description |
| --- | --- |
| [`current`](./current) | Print the current organization |
| [`unset`](./unset) | Clear the current organization of the active context |
| [`use`](./use) | Set the current organization for the active context |

---

Every command also accepts the [global options](../../global-options.md).
