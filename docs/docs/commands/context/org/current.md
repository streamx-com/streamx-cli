# `streamx context org current`

Print the current organization

```bash
streamx context org current [options]
```

The effective value: STREAMX_ORG if set, otherwise the active context's current-org.

## Options

| Option | Value | Description |
| --- | --- | --- |
| `-v`, `--verbose` |  | Print debug information |

---

Every command also accepts the [global options](../../global-options.md).
