# `streamx context project`

Manage the current project of the active context

```bash
streamx context project <command>
```

## Subcommands

| Command | Description |
| --- | --- |
| [`current`](./current) | Print the current project |
| [`unset`](./unset) | Clear the current project of the active context |
| [`use`](./use) | Set the current project for the active context |

---

Every command also accepts the [global options](../../global-options.md).
