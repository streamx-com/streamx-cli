# `streamx context project unset`

Clear the current project of the active context

```bash
streamx context project unset [options]
```

The current organization is kept. Idempotent. A STREAMX_PROJECT environment variable is not affected.

## Options

| Option | Value | Description |
| --- | --- | --- |
| `-v`, `--verbose` |  | Print debug information |

---

Every command also accepts the [global options](../../global-options.md).
