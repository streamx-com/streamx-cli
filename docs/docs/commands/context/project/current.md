# `streamx context project current`

Print the current project

```bash
streamx context project current [options]
```

The effective value: STREAMX_PROJECT if set, otherwise the active context's current-project.

## Options

| Option | Value | Description |
| --- | --- | --- |
| `-v`, `--verbose` |  | Print debug information |

---

Every command also accepts the [global options](../../global-options.md).
