# `streamx local`

Operate local StreamX instance

```bash
streamx local <command>
```

## Subcommands

| Command | Description |
| --- | --- |
| [`run`](./run) | Run a StreamX Mesh locally |

---

Every command also accepts the [global options](../global-options.md).
