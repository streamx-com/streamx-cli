# `streamx local run`

Run a StreamX Mesh locally

```bash
streamx local run [options]
```

## Options

| Option | Value | Description |
| --- | --- | --- |
| `-f`, `--file` | `<meshPath>` | Path to mesh definition file |
| `-v`, `--verbose` |  | Print debug information |

---

Every command also accepts the [global options](../global-options.md).
