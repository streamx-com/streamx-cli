# `streamx org get`

Display an organization

```bash
streamx org get [options] [<orgId>]
```

## Arguments

| Argument | Required | Description |
| --- | --- | --- |
| `<orgId>` | no | Organization ID (defaults to the current organization) |

## Options

| Option | Value | Description |
| --- | --- | --- |
| `-o`, `--output` | `<output>` | Specify output format: text, json, yaml |
| `-v`, `--verbose` |  | Print debug information |

---

Every command also accepts the [global options](../global-options.md).
