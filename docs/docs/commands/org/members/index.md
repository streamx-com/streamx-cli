# `streamx org members`

Manage organization members

```bash
streamx org members <command>
```

## Subcommands

| Command | Description |
| --- | --- |
| [`add`](./add) | Add an existing user to an organization |
| [`list`](./list) | List organization members |
| [`remove`](./remove) | Remove a member from an organization |
| [`set-role`](./set-role) | Change the role of an organization member |

---

Every command also accepts the [global options](../../global-options.md).
