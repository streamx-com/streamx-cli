# `streamx org`

Manage StreamX organizations

```bash
streamx org <command>
```

## Subcommands

| Command | Description |
| --- | --- |
| [`clusters`](./clusters/) | Inspect organization clusters |
| [`create`](./create) | Create an organization |
| [`delete`](./delete) | Delete an organization |
| [`get`](./get) | Display an organization |
| [`invitations`](./invitations/) | Manage organization invitations |
| [`list`](./list) | List organizations you have access to |
| [`members`](./members/) | Manage organization members |

---

Every command also accepts the [global options](../global-options.md).
