# `streamx org invitations`

Manage organization invitations

```bash
streamx org invitations <command>
```

## Subcommands

| Command | Description |
| --- | --- |
| [`accept`](./accept) | Accept an invitation to an organization |
| [`cancel`](./cancel) | Cancel a pending organization invitation |
| [`create`](./create) | Invite a user to an organization |
| [`list`](./list) | List pending organization invitations |

---

Every command also accepts the [global options](../../global-options.md).
