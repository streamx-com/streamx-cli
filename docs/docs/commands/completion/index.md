# `streamx completion`

Generate shell completion scripts

```bash
streamx completion <command>
```

## Subcommands

| Command | Description |
| --- | --- |
| [`bash`](./bash) | Generate bash completion script (use --help for setup instructions) |
| [`zsh`](./zsh) | Generate zsh completion script (use --help for setup instructions) |

---

Every command also accepts the [global options](../global-options.md).
