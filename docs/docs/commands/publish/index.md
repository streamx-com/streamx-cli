# `streamx publish`

Publish events

```bash
streamx publish <command>
```

## Subcommands

| Command | Description |
| --- | --- |
| [`event`](./event) | Publish a single event |
| [`events`](./events) | Publishes multiple events based on a directory structure and .eventtemplate files |
| [`stream`](./stream) | Publishes stream of events |

---

Every command also accepts the [global options](../global-options.md).
