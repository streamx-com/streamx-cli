# `streamx settings`

Modify StreamX settings

```bash
streamx settings <command>
```

## Subcommands

| Command | Description |
| --- | --- |
| [`event-templates`](./event-templates/) | Manage StreamX event templates |
| [`get`](./get) | Get settings property |
| [`list`](./list) | Display all settings properties |
| [`set`](./set) | Set settings property |
| [`unset`](./unset) | Unset settings property |

---

Every command also accepts the [global options](../global-options.md).
