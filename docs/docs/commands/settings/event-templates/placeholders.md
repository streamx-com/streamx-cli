# `streamx settings event-templates placeholders`

List the placeholders that may be used inside event templates

```bash
streamx settings event-templates placeholders [options]
```

Prints every placeholder that `publish event` substitutes when rendering an event template, along with a short description of what each one resolves to.

## Options

| Option | Value | Description |
| --- | --- | --- |
| `-o`, `--output` | `<output>` | Specify output format: text, json, yaml |
| `-v`, `--verbose` |  | Print debug information |

---

Every command also accepts the [global options](../../global-options.md).
