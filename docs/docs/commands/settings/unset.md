# `streamx settings unset`

Unset settings property

```bash
streamx settings unset [options] <key>
```

## Arguments

| Argument | Required | Description |
| --- | --- | --- |
| `<key>` | yes | Property key |

## Options

| Option | Value | Description |
| --- | --- | --- |
| `-v`, `--verbose` |  | Print debug information |
