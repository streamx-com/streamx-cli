# `streamx auth token revoke`

Revoke a personal access token

```bash
streamx auth token revoke [options] <id>
```

## Arguments

| Argument | Required | Description |
| --- | --- | --- |
| `<id>` | yes | The token id (from 'streamx auth token list') |

## Options

| Option | Value | Description |
| --- | --- | --- |
| `-v`, `--verbose` |  | Print debug information |
