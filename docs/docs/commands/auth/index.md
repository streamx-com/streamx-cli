# `streamx auth`

Manage StreamX authentication

```bash
streamx auth <command>
```

## Subcommands

| Command | Description |
| --- | --- |
| [`login`](./login) | Log in to StreamX |
| [`logout`](./logout) | Log out of StreamX |
| [`token`](./token/) | Manage personal access tokens |
| [`whoami`](./whoami) | Display the currently logged in user |

---

Every command also accepts the [global options](../global-options.md).
