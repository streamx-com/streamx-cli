# `streamx project repo`

Manage the Git repository connected to a project

```bash
streamx project repo <command>
```

## Subcommands

| Command | Description |
| --- | --- |
| [`get`](./get) | Show the repository connected to a project |
| [`remove`](./remove) | Disconnect the repository from a project |
| [`set`](./set) | Connect a repository to a project, or change its settings |
| [`ssh-key`](./ssh-key/) | Manage the SSH deploy key of the connected repository |

---

Every command also accepts the [global options](../../global-options.md).
