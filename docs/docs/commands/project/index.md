# `streamx project`

Manage StreamX projects

```bash
streamx project <command>
```

## Subcommands

| Command | Description |
| --- | --- |
| [`clusters`](./clusters/) | Manage the clusters a project runs on |
| [`create`](./create) | Create a project |
| [`delete`](./delete) | Delete a project |
| [`get`](./get) | Display a project, its clusters and its repository |
| [`list`](./list) | List projects in an organization |
| [`pending-changes`](./pending-changes) | List changes waiting to be applied to a project |
| [`repo`](./repo/) | Manage the Git repository connected to a project |
| [`status`](./status) | Show a project's deployment status |
| [`update`](./update) | Update a project's name or description |

---

Every command also accepts the [global options](../global-options.md).
