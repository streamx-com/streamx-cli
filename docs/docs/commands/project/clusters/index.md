# `streamx project clusters`

Manage the clusters a project runs on

```bash
streamx project clusters <command>
```

## Subcommands

| Command | Description |
| --- | --- |
| [`disable`](./disable) | Disable one cluster for a project |
| [`enable`](./enable) | Enable one more cluster for a project |
| [`list`](./list) | List clusters available to a project and whether they are enabled |
| [`set`](./set) | Set the full list of clusters a project runs on |

---

Every command also accepts the [global options](../../global-options.md).
